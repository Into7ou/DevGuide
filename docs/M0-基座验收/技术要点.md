# M0 基座验收 — 技术要点（面试可讲）

> 每个点用「是什么 → 作用 → 为什么」三句话讲清，点到为止。

## 1. 开源 License（改造的前提）
- **是什么**：开源许可证规定别人能否复制/修改/分发代码，常见宽松协议有 MIT、Apache-2.0。
- **作用**：我们是「基于开源项目改造」，开工前必须先确认基座有合法 License。
- **为什么**：没有 LICENSE 文件默认「保留所有权利」，拿来改造有法律风险。

## 2. 为什么选 spring-ai-alibaba 官方示例当基座
- **是什么**：阿里官方在 Spring AI 上扩展的 Java AI 框架，配套官方示例仓库（Apache-2.0）。
- **作用**：作为合法基座，复用它的骨架和示例组装业务。
- **为什么**：官方维护、许可证合法、技术栈匹配，而且「业务层自研」占比更高，面试更好讲。

## 3. PostgreSQL + PGvector 选型
- **是什么**：PostgreSQL 是开源关系型数据库，PGvector 是它的向量扩展。
- **作用**：一个库同时存业务数据（用户、技术栈）+ 向量（RAG 检索）。
- **为什么**：不用额外挂 Milvus 这类独立向量库，部署简单；项目规模小够用。

## 4. 技术栈全景（M0 定稿）
| 技术 | 作用 |
