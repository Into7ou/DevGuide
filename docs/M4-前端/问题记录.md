## 问题 1：vue-router 依赖版本冲突（已修）

- **现象**：`npm install vue-router`（不指定版本）报 ERESOLVE 依赖解析冲突。
- **根因**：默认装到了最新的 `vue-router@5.3.0`，它要求 `vite@^7 || ^8`，而本项目是 `vite@6.4.3`（且 @vitejs/plugin-vue 也锁 vite 6），版本不兼容。
- **解决**：显式装 `vue-router@4`（Vue3 + Vite6 的稳定主线）。
- **踩坑点**：不指定版本装依赖容易拉到「刚发布的新大版本」导致冲突；Vue3 项目应锁定 `vue-router@4`。

## 问题 2：后端启动失败（PostgreSQL 未运行）

- **现象**：后端启动报 `Connection to localhost:5432 refused`。
- **根因**：之前收尾时 PostgreSQL 容器已停止。
- **解决**：`docker compose up -d postgres` 重启容器后，后端正常启动（Flyway 迁移 + PGvector 均正常）。

## 问题 3：首轮遗漏了前端单元测试（已补）

- **现象**：M4 首轮只做了构建 + 联通验证，没写前端单元测试（与 M2/M3 后端不一致）。
- **解决**：补 Vitest + Vue Test Utils + happy-dom，抽出纯逻辑 `formatStars`/`filterStacks` 到 `utils/`，写 3 个测试文件共 6 个用例。
- **踩坑点**：前端也不能只靠「页面看起来对」就交付，可测的纯逻辑（格式化、过滤）和组件渲染要有测试兜底。
