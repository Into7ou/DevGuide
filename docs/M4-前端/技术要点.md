# M4 前端 — 技术要点（面试可讲）

> 每个点用「是什么 → 作用 → 为什么」三句话讲清，点到为止。

## 1. Vue Router（前端路由）
- **是什么**：Vue 官方的前端路由库，用 URL 管理多页面。
- **作用**：两个页面——技术栈清单（`/`）和技术栈详情（`/stack/:name`）。
- **为什么**：SPA 里不用刷新就能切换页面，且路由参数直接传给组件。

## 2. 设计 token（CSS 变量，统一风格）
- **是什么**：把颜色、间距、字体、圆角、阴影定义成一套 CSS 变量。
- **作用**：全站唯一的视觉来源（`tokens.css`），所有页面共用，保证风格统一。
- **为什么**：改一个 token 全站生效，避免每个页面各写各的颜色导致风格割裂。

## 3. 组件化（小组件封装）
- **是什么**：把重复 UI 拆成独立组件（AppHeader / StackCard / RepoCard / LearnPanel）。
- **作用**：清单卡片、仓库卡片、学习引导面板各是一个小组件。
- **为什么**：架构简单、易维护，避免一个文件几百行「大杂烩」。

## 4. Vite 开发代理（前后端联调）
- **是什么**：Vite dev server 把 `/api` 请求转发到后端 8080。
- **作用**：前端代码里直接写 `/api/v1/...`，开发时不用处理跨域。
- **为什么**：开发阶段前端 5173、后端 8080 分离，代理让它们「看起来同源」。

## 5. 设计系统 skill 驱动（避免 AI 味）
- **是什么**：用 `ui-ux-pro-max` skill 的 `--design-system` 生成本项目的视觉方向。
- **作用**：定下「深色开发者主题 + 极简瑞士风 + 绿色强调色」的基调。
- **为什么**：设计决策有据可依（而不是凭感觉），并规避了「低对比度、emoji 当图标」等常见坑。

## 6. 技术栈作用一览
| 技术 | 作用 |
|---|---|
| Vue3 + Vue Router | 页面结构 + 路由 |
| Vite + 代理 | 构建 + 前后端联调 |
| CSS 变量（tokens.css） | 全站统一视觉 |
| 小组件（4 个） | 复用 UI 模块 |
| ui-ux-pro-max skill | 设计决策来源 |
