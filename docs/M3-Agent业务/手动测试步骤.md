## 一、启动环境

```powershell

docker compose up -d postgres

# 2. 启动后端（自动读 .env，自动执行 Flyway 迁移）
scripts\run-backend.ps1

# 3. 启动前端（另开一个终端）
scripts\run-frontend.ps1
```

- 后端地址：http://localhost:18080
- 前端地址：http://localhost:5173

**预期**：返回 21 个技术栈，按名称排序，含 React / Spring Boot / Kubernetes 等。

### 2.2 技术栈详情（官方文档 + GitHub Top10）

**预期**：返回 `name=Remix`、`officialDocUrl=null`、`topRepos` 来自 GitHub 关键词搜索。

## 三、验证 RAG 学习引导（M3，核心）

### 3.1 首次生成（自动入库，约 30-60 秒）
```powershell
$body = @{ techStack = "React"; question = "React 怎么入门？" } | ConvertTo-Json
Invoke-RestMethod http://localhost:18080/api/v1/agent/learn -Method Post -ContentType "application/json" -Body $body
```
**预期**：
- `answer`：一段中文的 React 学习路线/核心概念讲解，非空。
- `citations`：非空数组，包含 react.dev 的官方文档 URL。

### 3.2 第二次生成（已入库，应秒回）
再执行一次上面的命令。
**预期**：很快返回（跳过入库），answer 正常、citations 非空。

### 3.3 换一个技术栈
```powershell
$body = @{ techStack = "Vue"; question = "Vue 怎么入门？" } | ConvertTo-Json
Invoke-RestMethod http://localhost:18080/api/v1/agent/learn -Method Post -ContentType "application/json" -Body $body
```
**预期**：首次入库 + 生成，citations 含 vuejs.org 的 URL。

## 四、边界情况验证

### 4.1 未知技术栈 → 应返回 400
```powershell
$body = @{ techStack = "不存在的技术栈"; question = "x" } | ConvertTo-Json
try { Invoke-RestMethod http://localhost:18080/api/v1/agent/learn -Method Post -ContentType "application/json" -Body $body } catch { $_.Exception.Response.StatusCode.value__ }
```
**预期**：400，错误信息含「未知技术栈」。

### 4.2 空 question → 使用默认问题
```powershell
$body = @{ techStack = "Flask"; question = "" } | ConvertTo-Json
Invoke-RestMethod http://localhost:18080/api/v1/agent/learn -Method Post -ContentType "application/json" -Body $body
```
**预期**：正常返回，answer 是「Flask 的学习路线和核心概念讲解」。

### 4.3 非法 JSON → 应返回 400
```powershell
# 发送一个坏 JSON
Invoke-WebRequest http://localhost:18080/api/v1/agent/learn -Method Post -ContentType "application/json" -Body '{"techStack": bad json'
```
**预期**：400，错误信息为 "Invalid request body"（不是 500）。
