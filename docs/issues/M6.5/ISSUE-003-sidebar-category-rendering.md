## 现象与根因

首页点击侧边栏“前端”等分类后，只有分类标题，没有对应卡片。预期应同时显示分类标题和该类技术栈。

前端已有 `filterByCategory`，按 API 返回的 `category` 等值筛选；分类属性保存在数据库。问题在 `StackListView.vue`：分类标题和卡片列表共用一条 `v-if/v-else-if/v-else` 链，有分类时标题分支阻止列表渲染。

真实数据中的 Nuxt/Next.js 均已属于 frontend。组件用例点击“前端”，预期 Nuxt 卡片，旧代码实际返回空列表，复现问题。

## 修改

- 将分类标题和列表内容分开渲染，保留现有筛选函数。
- 新技术原已在 DeepSeek Agent 的实体识别中分类；补充统一的四类用途说明，明确按技术用途和生态分类，SSR 前端框架归 frontend。
- C语言 原先固定赋值 backend，改为调用同一服务的 `classify`，由项目接入的 DeepSeek Agent 判断。
- 使用同一 `classify` 方法和项目实际模型配置，一次性复核现有 25 条数据：9 前端、7 后端、4 ML·数据、5 基础设施；全部与原值一致，因此无需修改数据库或新增迁移。
- 分类在新技术收录时确定，前端只读取和筛选；没有新增接口、定时任务或刷新时的模型调用。

## 验收

- 新组件用例串联实际侧边栏、Vue Router 和列表组件；依次验证四个分类，再点击“显示全部”，从失败到通过。
- 前端 28 项、后端 37 项测试通过，前端生产构建通过。
- 真实 Agent 复核明细保存在本地构建目录 `backend/target/category-review.json`；临时执行源码已移除。
- 本次没有浏览器视觉验收；交互通过组件测试验证。
