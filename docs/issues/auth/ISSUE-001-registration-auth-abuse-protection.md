# 自有注册登录与抗滥用保护

所属功能：身份认证与公网安全
创建日期：2026-09-04
更新日期：2026-09-04
Status: needs-triage

## 目标

在当前 GitHub OAuth 之外增加自有注册/登录能力，并强化认证、账号保护和公网抗滥用能力。该事项是上线后的明确必做优化，但不阻塞 M7 简历展示型首次部署。

## 已确认边界

- 匿名用户仅能使用公开展示访问，不能触发模型、联网搜索、动态发现或资料回写。
- 当前生成访问继续使用 GitHub OAuth。
- 自有账号的注册标识、认证因子、邮箱验证、找回流程和是否保留 GitHub OAuth 尚未决定。
- 登录认证不能单独防御 DDoS；应用层认证保护与边缘网络保护需要分别设计。

## 待设计内容

- 注册与登录方式：邮箱密码、邮件验证码、Passkey 或其他组合。
- 密码存储、邮箱验证、账号找回、会话撤销和敏感操作再认证。
- 登录/注册尝试限速、失败退避、账号与 IP 维度风控、Bot Challenge。
- Agent 生成配额、并发限制、单用户成本上限和异常调用审计。
- CDN/WAF、边缘限流、源站隐藏和告警策略。

## 验收标准（待专题确认）

- 注册、登录、退出、会话失效与账号恢复具备自动化安全回归。
- 暴力破解、凭据填充、批量注册和生成接口滥用受到限制。
- 源站不直接暴露，常见恶意流量可在边缘层拦截或限速。
- 安全事件不记录密码、Token、密钥或其他敏感原值。
