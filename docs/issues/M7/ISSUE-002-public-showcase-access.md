# 公开展示与登录生成访问

所属阶段：M7 部署
创建日期：2026-09-04
更新日期：2026-09-05
Status: ready-for-human

## 目标

让简历访问者无需 GitHub 授权即可浏览已有项目内容，同时确保匿名请求不能触发模型、动态发现、联网回写或其他可变成本操作。

## 当前行为

- `/api/v1/tech-stacks` 整体要求登录，匿名访问首页列表会得到 401。
- 已有详情与未知名称共用同一路径；未知名称会进入 Agent/Tavily 核验和动态转正，因此不能直接整体放行。
- 前端把 401 当普通加载失败展示，没有把用户引导到登录。

## 已确认方案

- 新增 `/api/v1/showcase/tech-stacks` 与 `/api/v1/showcase/tech-stacks/{name}` 公开只读路径。
- 公开列表只读取数据库已有条目；公开详情只解析已有名称或别名，未知名称返回 404。
- 公开详情可以返回通过现有缓存获取的 GitHub Top10，但不得调用 `TechStackDiscoveryService` 或执行数据库写入。
- 原动态技术栈、Agent、联网搜索和回写路径继续要求 GitHub OAuth 登录。
- 匿名用户触发需要生成访问的操作时，前端显示登录提示并提供登录入口。
- 已收录列表中的名称/分类筛选属于纯前端站内筛选，匿名用户继续可用；只有无现有匹配时的动态搜索和 Agent 操作需要登录。

## 验收标准

- 匿名列表和已有详情返回 200，未知公开详情返回 404。
- 回归测试证明公开未知名称不调用发现服务、模型、Tavily 或 upsert。
- 匿名生成接口仍返回 JSON 401；已登录行为保持不变。
- 前端匿名访问可浏览已有内容，需要动态搜索或生成时收到清晰登录提示。
- 匿名站内名称/分类筛选保持可用，不被登录提示打断。
- 前后端全量测试与生产构建通过。

## 验证结果

- 已新增公开只读列表与详情接口；未知名称返回 404，不进入动态发现。
- 前端匿名用户可筛选和浏览已收录内容；尝试动态搜索或 Agent 时展示 GitHub 登录提示。
- 后端全量 71 项、前端全量 38 项与 Vite 生产构建通过。
- Caddy/后端临时集成容器验证公开列表返回真实 JSON，而不是 SPA 回退页面。
- 尚待真实域名下由用户完成匿名浏览、登录后生成与浏览器交互验收，因此转为 ready-for-human。
