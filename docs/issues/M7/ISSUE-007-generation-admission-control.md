# 生成准入与成本熔断

所属阶段：M7 部署
创建日期：2026-09-04
更新日期：2026-09-05
Status: done

## 目标

在公网演示站调用模型、联网搜索或资料回写前执行服务端成本保护，同时保留未来迁移到分布式限流、任务队列和多实例部署的替换边界。

## 已确认方案

- 仅生产环境默认启用；本地开发默认关闭，不改变现有开发流程。
- 每个 GitHub 用户每 UTC 日最多 10 次 Agent 请求、20 次动态搜索。
- 全站最多同时执行 2 个生成任务。
- 超限返回 HTTP 429、稳定错误码和重试提示，并在任何下游计费或写入调用之前终止。
- M7 使用单实例内存状态，但配额规则、准入接口和状态存储职责分离。

## 高并发扩展边界

- Agent 和动态搜索业务入口只依赖生成准入接口，不直接访问内存 Map、计数器或 Semaphore。
- 后续可使用 Redis 原子计数/令牌桶替换内存配额状态，并用分布式并发控制或任务队列替换本机并发闸门。
- 多实例上线前还必须完成共享 Session、OAuth authorized-client 持久化与多实例回归测试；本任务不实现这些能力。
- 当前限额全部配置化，未来调整容量或按用户等级分配额度无需改动业务流程。

## 验收标准

- Agent 与动态搜索分别正确执行 10/20 次 UTC 日配额，且按认证用户隔离。
- 第 11 次 Agent 请求、第 21 次动态搜索及超过并发 2 的请求返回 429，且下游调用次数保持不变。
- 成功、异常和 SSE 取消均释放并发许可。
- `dev` 默认不限制，`prod` 缺少或非法限额配置时启动失败或采用文档化的安全默认值。
- 单元/集成测试可以替换准入实现，证明业务层未绑定单机状态结构。

## 验证结果

- 已增加可替换 GenerationAdmissionPolicy 边界和单实例内存实现；开发默认关闭、生产默认开启。
- Agent 10 次/UTC 日、动态搜索 20 次/UTC 日、全站并发 2 均配置化；拒绝返回 429、稳定错误码与 Retry-After。
- 同用户/不同用户/不同操作隔离、并发拒绝、重复释放、开发禁用与 Spring Bean 创建测试通过。
- SSE 使用 doFinally 释放许可，覆盖完成、异常和取消信号；动态发现仅在未知名称进入下游前取得许可。
- 后端全量 71 项测试及生产 profile 容器启动通过。
