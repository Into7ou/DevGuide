## 问题 1：Maven 无法写入工作区外的本地仓库

- **现象**：`mvn compile` 报 `AccessDeniedException: D:\maven\local\...`。
- **根因**：本机 `settings.xml` 配了 `localRepository=D:/maven/local`（工作区之外），沙箱（workspace-write）禁止写工作区外；且 `-Dmaven.repo.local` 覆盖未生效。
- **解决**：新建 `maven-settings.xml`（本地仓库指向工作区内 `.m2` + 阿里云镜像），用 `mvn -s maven-settings.xml` 指定。
- **踩坑点**：`-Dmaven.repo.local` 在本机没有覆盖 settings.xml 里的 localRepository，用 `-s` 指定 settings 文件最稳。

## 问题 2：spring-ai-alibaba 依赖版本解析失败

- **现象**：`'version' for spring-ai-alibaba-starter-dashscope is missing`。
- **根因**：① `1.1.0.0` / `1.1.0.0-RC1` 不在 Maven Central；② 1.1.2.x 起构件拆分——核心 BOM 不再管理模型 starter，模型 starter 由 `spring-ai-alibaba-extensions-bom` 管理。
- **解决**：spring-ai-alibaba 与 extensions 都用稳定版 `1.1.2.3`，并同时导入 extensions-bom。
- **踩坑点**：官方 examples 用 `1.1.0.0-RC1`（需本地 install 框架源码），不是发布版；要用 Maven Central 上的稳定版 `1.1.2.3`。

## 问题 3：Docker 命令被沙箱拦截

- **现象**：`docker compose up` 报 `Access is denied`（`//./pipe/dockerDesktopLinuxEngine`）。
- **根因**：沙箱阻止访问 Docker 命名管道。
- **解决**：用 `danger-full-access` 升级权限重试一次（用户已授权）。
- **踩坑点**：Docker CLI 通过命名管道与守护进程通信，沙箱默认拦截。

## 问题 4：PowerShell 脚本中文乱码

- **现象**：`run-backend.ps1` 解析报错（字符串终止符缺失），中文变乱码。
- **根因**：无 BOM 的 UTF-8 被按 GBK 读取。
- **解决**：脚本改为纯 ASCII（英文）。
- **踩坑点**：Windows 下 `.ps1` 含中文且无 BOM 会乱码，脚本用英文最稳。

## 问题 5：DeepSeek 无 embedding 模型

- **现象**：RAG 需要 embedding，但 DeepSeek 只提供对话模型。
- **解决**：`spring.ai.deepseek.embedding.enabled=false`；用 DashScope `text-embedding-v2`（1536 维）补齐。

## 问题 6：npm 缓存目录在工作区外被拦截

- **现象**：`npm install` 报「无法写入 C:\Users\ASUS\AppData\Local\npm-cache」。
- **根因**：npm 默认缓存/日志目录在用户目录（工作区外），沙箱禁止写入。
- **解决**：`npm install --cache D:/.../.npm-cache` 把缓存重定向到工作区内；`.npm-cache/` 加入 gitignore。

## 问题 7：esbuild 的 child_process.spawn 被沙箱拦截

- **现象**：esbuild postinstall 与 `vite build` 报 `spawn EPERM`。
- **根因**：沙箱拦截 Node.js `child_process.spawn`（管道 stdio）；esbuild 需 spawn 原生二进制。
- **解决**：安装用 `--ignore-scripts`（esbuild 二进制由 optionalDependencies 提供）；构建时用 `danger-full-access` 升级权限。
- **踩坑点**：这是沙箱环境限制，用户本机正常跑 `npm run dev` 无此问题。
